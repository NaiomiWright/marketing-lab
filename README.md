# Marketing Lab

Portfolio project by Naiomi Wright. Brackenfold Settle is a made-up product.

This is a portfolio project built with Claude Code. It shows a full marketing campaign for a made-up brand, from brief to launch.

All names, products and numbers here are invented.

## Folders

- `plan/` - plans and briefs
- `assets/images/` - campaign images
- `external/` - work for customers and the public
- `internal/` - work for internal teams
- `site/` - the campaign website
- `data/` - made-up campaign data
