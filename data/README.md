# Campaign data

Portfolio project by Naiomi Wright. Brackenfold Settle is a made-up product.

All numbers in this folder are made up for practice.

- `brackenfold-results.csv` - the raw daily results, 23 November to 20 December 2026. Spend is advertising and email cost only. The file has no line of its own, so it stays a clean data file.
- `results.xlsx` - the raw rows, a summary by channel and week, and the results against the plan's targets.
- `readout.md` - the campaign readout: Naiomi's answers, Claude's answers and where they agree.
